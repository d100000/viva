# Viva 0.15.0 - 双登录与 AI 结果追踪

## 重点更新

- **验证码 / 密码双登录**：登录窗口默认使用邮箱验证码，也可切换到账号密码登录。
- **密码注册与找回**：新账号可在邮箱验证后设置密码，已有账号可通过验证码安全重设。
- **同一套登录状态**：两种登录方式共用 Access Token、Refresh Token 和设备会话，重启后自动恢复。
- **密码管理器支持**：表单标注了用户名、当前密码、新密码和一次性验证码语义，改善 macOS 自动填充。
- **AI 结果追踪**：客户端会区分“服务端已返回”与“文字已真正上屏”，并回报超时、取消、回退和客户端护栏拒绝等结果。

## 安全与运营

- 新密码由服务端使用 Argon2id 保护，注册和改密必须先完成邮箱验证。
- 错误账号、错误密码和未设密码账号返回相同错误，并受 IP、邮箱、设备和全局频率限制保护。
- 密码登录会与验证码登录一样更新后台的最近登录 IP、设备 ID、系统和客户端信息。
- 未登录时仍不会注册全局热键，不影响其它应用输入。

## 安装 / 升级

```bash
curl -fsSL https://raw.githubusercontent.com/d100000/viva/main/install.sh | bash
```

也可下载 DMG，打开后把 Viva 拖入 Applications。Viva 启动后每 24 小时检查 GitHub Releases；默认会在空闲时自动下载、校验、替换并重启。

> 系统要求：macOS 14 或更高版本，Apple Silicon。本版本延续固定自签名身份，尚未使用 Apple Developer ID 公证。
