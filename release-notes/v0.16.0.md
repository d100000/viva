# Viva 0.16.0 - 加速引擎与按需麦克风

## 重点更新

- **默认按需启动**：麦克风引擎默认在空闲时关闭，只在语音输入或麦克风测试时启动，输入结束后立即释放。
- **加速引擎**：设置中新增用户可选开关。开启后引擎会提前就绪，保留热键之前的预缓冲音频，减少句首内容遗漏，让整句话识别得更完整。
- **即时切换**：保存设置后无需重启 Viva，可在常驻和按需模式之间切换。
- **明确的隐私提示**：设置页会说明开启加速引擎后，macOS 在空闲时也会显示麦克风正在使用。
- **蓝牙保护**：蓝牙输入设备仍按需启动，避免长时间进入 HFP 通话模式导致音质降低。

## 使用说明

前往“设置 → 麦克风输入 → 加速引擎”：

- 关闭（默认）：空闲时不持续使用麦克风，按下热键时再启动。
- 开启：获得更快的录音起步和句首预缓冲，但 macOS 会在空闲时显示麦克风使用指示。

## 安装 / 升级

```bash
curl -fsSL https://raw.githubusercontent.com/d100000/viva/main/install.sh | bash
```

也可下载 DMG，打开后把 Viva 拖入 Applications。Viva 启动后每 24 小时检查 GitHub Releases；默认会在空旲时自动下载、校验、替换并重启。

> 系统要求：macOS 14 或更高版本，Apple Silicon。本版本延续固定自签名身份，尚未使用 Apple Developer ID 公证。
